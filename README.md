# Eventora — Event Management Website

Eventora is a responsive front-end event discovery and management website built with HTML, CSS and vanilla JavaScript for a web designing student project.

## Features
- Responsive landing page and navigation
- First-visit city/area prompt; location is entered manually and saved in Local Storage
- Light and dark themes
- Event cards with images, categories, dates, venues and sample prices
- Search by event title, category, venue or description
- Category filters
- Detailed event view with description, highlights, audience and schedule
- Registration form with basic validation
- Demo registrations saved in browser Local Storage

## Run locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html` to open it in a browser.

## Project files
- `index.html` — page structure and dialogs
- `style.css` — layout, styling and responsive design
- `script.js` — event data, filtering, theme, location prompt and registration
- `README.md` — project documentation

## Important limitations
The listed events, dates, venues, schedules and prices are sample demonstration data, not verified real-world events. The location prompt asks for a city or area only; it does not request GPS or a home/street address. Registration is stored only in the visitor's browser and is not sent to an organiser. This is a front-end demonstration and does not include a backend database or payment system.
